# PDF-HR Manifold Training

`ManifoldTraining` contains the offline data pipeline used to build and train your own PDF-HR.

## Contents

```text
ManifoldTraining/
├── assets/g1skel29/       # G1 URDF and meshes used for joint limits
├── configs/               # Runnable training configs and templates
├── eval/                  # Offline checkpoint evaluation
├── sample/                # Dataset assembly and field-sample generation
├── tools/BonesSEED_tools/ # BONES-SEED preprocessing and split generation
├── tools/LaFAN_tools/     # LaFAN1 preprocessing and split generation
├── data.py                # Memory-mapped training data loader
└── train.py               # Shared pose/velocity/acceleration trainer
```

## Data location

Set `DATASET_ROOT` to the directory containing the downloaded datasets and all generated PDF-HR data.

```bash
export DATASET_ROOT=/path/to/datasets
```

## Unified motion format

Both preprocessing pipelines produce C-contiguous `float32` NPY arrays with
shape `(T, 97)`:

| Slice   | Width | Meaning                                       |
| ------- | ----- | --------------------------------------------- |
| `0:4`   | 4     | normalized root quaternion in `xyzw` order    |
| `4:7`   | 3     | world-frame root angular velocity, rad/s      |
| `7:10`  | 3     | world-frame root angular acceleration, rad/s² |
| `10:39` | 29    | joint positions, rad                          |
| `39:68` | 29    | joint velocities, rad/s                       |
| `68:97` | 29    | joint accelerations, rad/s²                   |

Root translation is deliberately omitted. BONES-SEED is processed at 120 FPS;
retargeted LaFAN1 is processed at 30 FPS.

## Preprocess motion datasets

Download and extract both datasets under your own `DATASET_ROOT`.

- [LaFAN1 Retargeting Dataset](https://huggingface.co/datasets/lvhaidong/LAFAN1_Retargeting_Dataset) is used for small-scale training tests, pipeline validation, and quick smoke runs.
- [BONES-SEED](https://huggingface.co/datasets/bones-studio/seed) is used for full-scale sample generation and complete PDF-HR training.

The preprocessing scripts expect the following source formats:

- **LaFAN1 Retargeting**: headerless CSV at 30 FPS. Each row contains root position XYZ (3), root quaternion `xyzw` (4), and 29 G1 joint positions in radians, for 36 columns total.
- **BONES-SEED**: headered G1 CSV at 120 FPS. Each row contains a frame index, root translation XYZ, root Euler XYZ in degrees, and 29 G1 joint positions in degrees. Keep `seed_metadata_v004.csv` under the dataset's `metadata/` directory for split generation.

Expected downloaded-data layout:

```text
$DATASET_ROOT/
├── LAFAN1_Retargeting/
│   └── g1/
│       ├── dance1_subject1.csv
│       ├── run1_subject2.csv
│       └── ...
├── BonesSEED_G1/
│   ├── g1/
│   │   └── csv/
│   │       ├── 220720/
│   │       │   └── <motion>.csv
│   │       ├── 231116/
│   │       │   └── <motion>.csv
│   │       └── ...
│   └── metadata/
│       └── seed_metadata_v004.csv
└── PDF-HR/                 # Generated by the commands below.
```

### Retargeted LaFAN1

Pre-process the Retargeted LaFAN1

```bash
python ManifoldTraining/tools/LaFAN_tools/preprocess.py \
  "$DATASET_ROOT/LAFAN1_Retargeting/g1" \
  "$DATASET_ROOT/PDF-HR/processed_data/LaFAN1_G1_processed"

python ManifoldTraining/tools/LaFAN_tools/generate_motion_split_file.py \
  --data-root "$DATASET_ROOT/PDF-HR/processed_data/LaFAN1_G1_processed" \
  --output-dir ManifoldTraining/sample/split_files \
  --split-name lafan_locomotion
```

This LaFAN split generator selects filenames containing `walk`, `run`, or `sprint`. Edit `INCLUDE_FIELDS` in the generator to change that policy; an empty list includes every motion.

### BONES-SEED

```bash
python ManifoldTraining/tools/BonesSEED_tools/preprocess.py --overwrite \
  "$DATASET_ROOT/BonesSEED_G1/g1/csv" \
  "$DATASET_ROOT/PDF-HR/processed_data/BonesSEED_G1_processed"

python ManifoldTraining/tools/BonesSEED_tools/generate_motion_split_file.py \
  --data-root "$DATASET_ROOT/PDF-HR/processed_data/BonesSEED_G1_processed" \
  --metadata "$DATASET_ROOT/BonesSEED_G1/metadata/seed_metadata_v004.csv" \
  --output-dir ManifoldTraining/sample/split_files \
  --target-samples all \
  --split-name bones_seed
```

The split generator supports package balancing, package inclusion, keyword exclusion, optional mirrored motions, etc.

## Assemble a dataset

Motions will be streamed into one memory-mapped `(N, 97)` array by running following command:

```bash
# LaFAN1
python ManifoldTraining/sample/generate_split_dataset.py \
  --data-root "$DATASET_ROOT/PDF-HR/processed_data/LaFAN1_G1_processed" \
  --split-file ManifoldTraining/sample/split_files/lafan_locomotion.txt \
  --output-dir "$DATASET_ROOT/PDF-HR/dataset"

# BONES-SEED
python ManifoldTraining/sample/generate_split_dataset.py \
  --data-root "$DATASET_ROOT/PDF-HR/processed_data/BonesSEED_G1_processed" \
  --split-file ManifoldTraining/sample/split_files/bones_seed.txt \
  --output-dir "$DATASET_ROOT/PDF-HR/dataset"
```

## Generate field samples

Each pose sample contains a 32-dimensional input followed by two scalar distance targets, for a total row size of 34:

| Columns | Size | Contents                        | Normalization |
| ------- | ---- | ------------------------------- | ------------- |
| 0-31    | 32   | Pose field input                | none          |
| 32      | 1    | Root-plus-joint distance target | divided by 30 |
| 33      | 1    | Joint-only distance target      | divided by 29 |

Generate samples for PDF-HR training by running following commands:

```bash
# LaFAN1: small-scale test (single GPU)
python ManifoldTraining/sample/generate_pose_samples.py \
  --dataset-file "$DATASET_ROOT/PDF-HR/dataset/lafan_locomotion.npy" \
  --output-dir "$DATASET_ROOT/PDF-HR/samples/pose" \
  --cache-dir "$DATASET_ROOT/PDF-HR/faiss_index_cache/lafan_locomotion/pose" \
  --rerank-candidates 1000 --samples-per-batch 1_000_000 --batch-num 8

# BONES-SEED: full training (single GPU)
python ManifoldTraining/sample/generate_pose_samples.py \
  --dataset-file "$DATASET_ROOT/PDF-HR/dataset/bones_seed.npy" \
  --output-dir "$DATASET_ROOT/PDF-HR/samples/pose" \
  --cache-dir "$DATASET_ROOT/PDF-HR/faiss_index_cache/bones_seed/pose" \
  --rerank-candidates 1000 --samples-per-batch 1_000_000 --batch-num 120

# BONES-SEED: full training (multiple GPUs)
torchrun --nproc_per_node=<GPU_COUNT> ManifoldTraining/sample/generate_pose_samples.py \
  --dataset-file "$DATASET_ROOT/PDF-HR/dataset/bones_seed.npy" \
  --output-dir "$DATASET_ROOT/PDF-HR/samples/pose" \
  --cache-dir "$DATASET_ROOT/PDF-HR/faiss_index_cache/bones_seed/pose" \
  --rerank-candidates 1000 --samples-per-batch 1_000_000 --batch-num 120
```

## Training

Runnable configurations:

| Dataset                    | Configuration          |
| -------------------------- | ---------------------- |
| Full training (BONES-SEED) | `pose_BS100_120M.json` |
| Small-scale test (LaFAN1)  | `pose_lafan.json`      |

Both release configurations train the 29DoF joint-only target (`root: false`).

Create your own training config by editing `pose_template.jsonc`. 

Single GPU:

```bash
# single GPU
python -m ManifoldTraining.train \
  --config ManifoldTraining/configs/pose_BS100_120M.json

# multiple GPUs
torchrun --nproc_per_node=<GPU_COUNT> ManifoldTraining.train \
  --config ManifoldTraining/configs/pose_BS100_120M.json
```

Checkpoints are written to:

```text
<output_dir>/<run_name>/epoch_XXXX.pt
<output_dir>/<run_name>/latest.pt
```

## Evaluation and visualization

Evaluate a checkpoint on a 97D dataset, field-ready input, or generated sample shards:

```bash
python -m ManifoldTraining.eval.evaluate_distance_field \
  --checkpoint /path/to/checkpoint.pt \
  --dataset /path/to/dataset.npy \
  --device cuda
```

The evaluator streams data, reports summary statistics and configurable distance intervals, and writes JSON under `ManifoldTraining/eval/results/` by default.

Plot one generated sample file's target distribution:

```bash
python ManifoldTraining/sample/visualize_sample_distribution.py \
  /path/to/batch_0000.npy \
  --distance-kind 29dof --bins 10
```

The plot is saved to `ManifoldTraining/sample/distribution.png`.
